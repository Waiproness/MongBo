# MongBo Desktop Implementation Plan

> Execute inline using the coding workflow; no delegation is needed.

Goal: a Windows x64 offline desktop companion, distributed as a ZIP containing MongBo.exe. Reuse PetActor, the React studio, the library popup, and portable JSON. Preserve the browser extension and website. Online friends, chat integrations, auto-start and automatic updates remain future work.

1. Add an Electron main process and sandboxed preload. Serve bundled assets over a local custom protocol. Validate IPC senders and stored character data, deny remote navigation and permissions, and expose only storage and explicit app actions.
2. Add a transparent overlay renderer using the existing actor and multi-pet library. Click through empty regions, retain pointer input during dragging, use a monitor's work area, and provide tray actions for management, studio, visibility, pause, monitor selection and quit.
3. Reuse the studio and library through a desktop storage adapter. Import JSON additively; per-pet hide and confirmed deletion remain available. Display desktop-specific help.
4. Build desktop assets separately, copy Electron runtime and required licenses into a distributable folder, and create an unsigned Windows x64 ZIP. Keep large desktop artifacts outside the extension ZIP and Cloudflare upload.
5. Verify validation, existing tests, website/extension builds, actual Electron sandbox/storage/import/multi-pet/throwing behavior, persistence and click-through. Verify the packaged executable launches. Document exact install, update, quit and data locations and the unsigned-app limitation.
