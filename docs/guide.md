# MongBo — มองโบ๋

เพื่อนตัวเล็กสำหรับ introvert สาย IT แต่งตัวละคร แล้วให้น้องอยู่เป็นเพื่อนระหว่างทำงานและท่องเว็บ

React 19 + TypeScript + Vite. ตัวละคร SVG ต้นฉบับและส่วนขยาย Manifest V3 สำหรับ Brave / Chrome / Edge ไม่มีบัญชี เซิร์ฟเวอร์ข้อมูล หรือ AI API

## MongBo Desktop Portable — Windows x64

ตั้งแต่ 0.10.1 ใช้ `MongBo-Portable-<version>-windows-x64.exe` ไฟล์เดียว ดาวน์โหลดแล้วเปิดได้เลย ไม่ต้องติดตั้งหรือแตก ZIP ตัว launcher จะเตรียมไฟล์ runtime ในโฟลเดอร์ชั่วคราวให้เอง แล้วล้างเมื่อออกจากแอป ข้อมูลยังอยู่ที่ `%APPDATA%/MongBo` และใช้ร่วมกับรุ่น Desktop เดิมได้

สร้างด้วย `npm run desktop:portable` ผลลัพธ์อยู่ใน `dist/portable` ใช้ electron-builder portable target แบบสิทธิ์ผู้ใช้ทั่วไป ไม่สร้างตัวติดตั้ง ไม่เปิดตอนบูต และไม่เผยแพร่อัตโนมัติ

Runtime ไม่รวม electron-builder ซึ่งเป็นเครื่องมือสำหรับ build เท่านั้น npm audit ของเครื่องมือ build มีคำเตือน moderate จาก minimatch ใน dependency เก่า จึงใช้เฉพาะ path และไฟล์ build ที่เชื่อถือได้ ไม่รับโครงการหรือ glob จากภายนอก ไม่มีการบังคับ downgrade หรือ override API ข้าม major เพื่อซ่อนคำเตือน

### รุ่น ZIP / โฟลเดอร์เดิม (ยังสร้างได้ด้วย desktop:pack)


รุ่นทดลองออฟไลน์ใช้ Electron พร้อมหน้าต่างโปร่งใสอยู่เหนือโปรแกรมอื่น พื้นที่ว่างคลิกทะลุ ตัวละครเดินบนขอบล่างของ work area เหนือ taskbar แสดงหลายตัวพร้อมกัน ลากและโยนแบบ projectile ได้

1. แตก ZIP `MongBo-<version>-windows-x64.zip` ทั้งหมดลงโฟลเดอร์ถาวร แล้วเปิด `MongBo.exe` ไม่ต้องติดตั้ง Node.js หรือ Electron แยก
2. หน้าจัดการเพื่อนเปิดอัตโนมัติ นำเข้า `.mongbo.json` จากเว็บเพื่อเพิ่มเพื่อน หรือเปิดสตูดิโอในแอปเพื่อสร้างใหม่ กด **แสดงบนเดสก์ท็อป** หลังบันทึก
3. เปิด/ปิดสวิตช์แต่ละตัวเพื่อแสดง/ซ่อน กดลบแล้วกดยืนยันเพื่อลบเฉพาะคลัง Desktop
4. คลิกขวาที่ตัวละครหรือไอคอน MongBo ข้างนาฬิกา เพื่อเปิดสตูดิโอ จัดการเพื่อน พัก ซ่อน เลือกหน้าจอ หรือ **ออกจาก MongBo** การปิดหน้าสตูดิโอไม่ปิดตัวละคร
5. อัปเดตโดยออกจากแอปก่อน แล้วแตก ZIP รุ่นใหม่ลงโฟลเดอร์ใหม่ ข้อมูลยังเก็บที่ `%APPDATA%/MongBo/companions.json` การลบโฟลเดอร์แอปไม่ลบข้อมูลนี้ สำรองตัวละครเป็น JSON ก่อนล้าง AppData

เว็บ ส่วนขยาย และ Desktop ใช้คลังแยกกัน ส่งออก/นำเข้า JSON เพื่อย้ายตัวละคร ไม่มีบัญชี ระบบออนไลน์ แชต เปิดตอนบูต หรืออัปเดตอัตโนมัติ รุ่นนี้ยังไม่เซ็นแอป Windows อาจเตือนหรือบล็อกตามนโยบายเครื่อง ไม่ควรปิดระบบความปลอดภัยเพื่อเปิดแอป

สำหรับพัฒนาและแพ็กบน Windows x64:

```sh
npm ci --ignore-scripts
node node_modules/electron/install.js
npm run desktop:build
npm run desktop:start
npm run desktop:pack
```

ผลลัพธ์อยู่ใน `dist/desktop/MongBo-win32-x64` และ ZIP อยู่ข้างโฟลเดอร์นี้ แพ็ก Desktop แยกจาก `dist/site` และ ZIP ส่วนขยาย จึงไม่ทำให้ดาวน์โหลดส่วนขยายใหญ่ขึ้น ตัวแอปโหลดเฉพาะไฟล์ที่รวมมา ปิด Node ใน renderer เปิด sandbox/context isolation ตรวจ IPC และไม่เชื่อมเครือข่าย ฟอนต์และใบอนุญาต Electron/Chromium รวมอยู่ในแพ็ก

## เปิดเว็บในเครื่อง

ต้องมี Node.js 24+ และ Python 3 สำหรับแพ็ก ZIP

```sh
npm ci --ignore-scripts
npm run dev
```

เปิด http://127.0.0.1:5173

## สร้างเว็บและส่วนขยาย

```sh
npm run build
```

- `dist/site` เว็บพร้อมนำไปโฮสต์
- `dist/extension` ส่วนขยายที่แตกไฟล์แล้ว ใช้กับ Load unpacked
- `dist/site/downloads/mongbo-brave.zip` ZIP สำหรับแจกส่วนขยาย

## ติดตั้งบน Brave

Brave, Edge และ Opera ใช้ `mongbo-chromium.zip` ร่วมกันได้ แตกไฟล์แล้วเปิด `brave://extensions`, `edge://extensions` หรือ `opera://extensions` เปิด Developer mode กด Load unpacked เลือกโฟลเดอร์ที่มี `manifest.json` รีเฟรชแท็บเว็บไซต์เดิมหลังติดตั้ง

Chrome ใช้ manifest Chromium เดียวกัน เว็บสตูดิโอทดสอบแล้ว แต่ยังไม่ได้ยืนยันส่วนขยายผ่านการติดตั้งจริงใน Chrome จึงยังไม่อยู่ในรายชื่อที่ทดสอบผ่าน ส่วน Firefox พักไว้ก่อน

Build สร้าง `dist/extension` และ ZIP ใน `dist/site/downloads` ลิงก์ `mongbo-brave.zip` เดิมยังคงใช้ได้ ข้อมูลแต่ละเบราว์เซอร์แยกกัน ย้ายด้วยไฟล์ `.mongbo.json` ได้

1. เปิด `brave://extensions`
2. เปิด Developer mode
3. กด **Load unpacked** เลือกโฟลเดอร์ `dist/extension` ที่มี `manifest.json`
4. เปิดเว็บไซต์ HTTP/HTTPS ทั่วไป หรือรีเฟรชแท็บเดิมหนึ่งครั้ง
5. คลิกไอคอน MongBo เพื่อเปิด/ปิด พักการเดิน ซ่อนรายเว็บ หรือเปิดสตูดิโอ

ส่วนขยายต้องได้รับสิทธิ์เข้าถึงเว็บไซต์ที่ต้องการแสดงตัวละคร การติดตั้งและให้สิทธิ์เป็นขั้นตอนที่ผู้ใช้ทำเอง

## สร้างและพาน้องไปด้วย

ตั้งแต่ 0.9.0 ส่วนขยายแสดงเพื่อนหลายตัวพร้อมกันได้ ติดตั้ง ZIP เพียงครั้งแรก จากเว็บให้ส่งออกตัวละครเป็น `.mongbo.json` แล้วกด **นำเข้าตัวละครจากเว็บ** ใน popup ตัวใหม่จะเพิ่มเข้าคลังและเดินพร้อมตัวเดิม หาก ID ซ้ำจะเพิ่มเป็นสำเนาใหม่ คลังสูงสุด 30 ตัวและไม่ลบตัวเก่าเมื่อเต็ม

ในหัวข้อ **เพื่อนในส่วนขยาย** เปิด/ปิดสวิตช์แต่ละตัวเพื่อแสดงหรือซ่อนโดยไม่ลบ กด **ลบ → ยืนยันลบ** เพื่อนำตัวนั้นออกจากคลังส่วนขยาย ปุ่มพัก/ซ่อนรายเว็บไซต์ควบคุมทุกตัว ข้อมูลเว็บและส่วนขยายแยกกัน การลบในส่วนขยายไม่ลบไฟล์ JSON ต้นฉบับหรือคลังบนเว็บ

การอัปเดตส่วนขยาย: แตก ZIP ใหม่ลงโฟลเดอร์เดิมแล้วกด Reload ในหน้าส่วนขยาย อย่ากด Remove เพราะอาจล้างข้อมูลส่วนขยาย ส่งออกตัวละครสำรองจากสตูดิโอก่อนย้ายหรือลบส่วนขยาย

- เลือกตัวละครสำเร็จ 16 แบบ สีตั้งต้น 8 สี และใบหน้า 4 แบบ
- เลือกสีอิสระผ่านตัวเลือกสีหรือพิมพ์ HEX แบบ `#RGB` / `#RRGGBB` เก็บสีโปรดในพาเลตได้
- เลือกชุด 15 แบบ ของสวมศีรษะ 19 แบบ และแว่น 6 แบบ ใส่สามหมวดพร้อมกันได้ ปรับสีชุดและของสวมศีรษะแยกได้
- ชุดปรับตามรูปร่างและตัดขอบเข้ากับลำตัว ปีก/แขนอยู่หน้าชุด ส่วนผ้าคลุมอยู่หลังตัวละคร
- ในแท็บ **ชุดและของ** เลือกของแล้วเปิด **ปรับให้พอดีตัว** เพื่อเลื่อนซ้าย–ขวา ขึ้น–ลง และปรับความกว้าง/สูง แยกชุด ศีรษะ และแว่น กด **คืนค่าพอดีตัว** เพื่อกลับไปใช้ค่าตามรูปร่าง
- ค่าปรับชุดเก็บไปกับตัวละคร ทั้งในคลัง ไฟล์นำเข้า/ส่งออก PNG และส่วนขยาย รูปวาดเองจัดตำแหน่งจากขอบภาพที่มีสีและปรับละเอียดได้
- แท็บ **คำพูด** เพิ่ม/แก้ไข/ลบได้ 20 ข้อความ ข้อความละ 120 ตัวอักษร กด **ลองพูด** หรือปุ่มเล่นข้างข้อความเพื่อทดสอบในห้อง
- คลิกตัวละครหรือปุ่ม **ให้น้องพูด** เพื่อพูดวนทีละข้อความ เปิด **ให้น้องพูดวนเอง** เมื่อต้องการ ตั้งช่วงได้ 15–180 วินาที ปิดไว้เป็นค่าเริ่มต้นและไม่พูดเองเมื่อแท็บซ่อนอยู่
- คำพูดบันทึกไปกับตัวละครและใช้ในส่วนขยายได้ กล่องข้อความตัดบรรทัดและย้ายให้อยู่ในขอบหน้าจอ รองรับไฟล์ตัวละครสูงสุด 32 KB
- เลือกสีหน้าได้ 20 อารมณ์ เช่น สบายใจ ตื่นเต้น ตกหลุมรัก ตั้งใจทำงาน งอน และมึน บันทึกไปกับตัวละครได้
- เส้นขอบตัวละคร ชุด หมวก แว่น และรายละเอียดแพนด้าใช้เทากลางแทนสีอมเขียว แว่นโปร่งใสไม่ผสมสีตัวครีมจนดูเขียว พาเลตสำเร็จเปลี่ยนสีเขียวเป็นทรายอุ่น สีที่เลือกเองและพิกเซลในภาพวาดยังคงเดิม
- เดินเฉพาะพื้นขอบล่างของห้องหรือหน้าจอเว็บไซต์อื่น ตัวที่มีขาใช้เท้าป้อมแนวนอนติดใต้ลำตัวตามภาพอ้างอิง รวมถึงเจ้าโมจิ โดยยังใช้แอนิเมชันสลับขาปัจจุบัน ผีน้อย เห็ด หมึก และตัววาดเองไม่มีเท้าที่เติมขึ้นมา หูขยับเฉพาะแมว กระต่าย หมี จิ้งจอก แพนด้า และสุนัข ไม่มีแขนที่สร้างเติมขึ้นมา ปีก/ชิ้นส่วนเดิมของตัวละครคงรูปทรงเดิม ความเร็วสัมพันธ์กับความซน
- ลากน้องขึ้นแล้วปล่อยจะตกตามแรงโน้มถ่วง ทำหน้าตกใจกลัว และย่อตัวตอนถึงพื้นพร้อมหน้ามึนชั่วครู่ ก่อนกลับเป็นอารมณ์ที่เลือกไว้ ภาพวาดเองใช้เครื่องหมายตกใจข้างตัวแทนการวาดทับใบหน้าเดิม
- ตอนจับลอย น้องแกว่งตามความเร็วการลากซ้าย/ขวา หูที่มีอยู่ขยับตาม และค่อย ๆ หยุดเมื่อมือหยุด สะบัดแล้วปล่อยจะพุ่งตามทิศและความเร็วมือทั้งสองแกน ลอยเป็นวิถีโค้งก่อนตกกลับพื้น จับค้างก่อนปล่อยจะเป็นการปล่อยตกธรรมดา ชนขอบจอแล้วลดแรงย้อนกลับ และไม่หลุดเหนือจอ
- เดินซ้าย/ขวาจะกลับทิศทั้งตัวและท่าก้าว พร้อมเอนและมองตามทางเดิน กล่องคำพูดไม่กลับด้าน รูปวาดเองกลับทิศทั้งภาพโดยไม่แก้ข้อมูลพิกเซลที่บันทึก
- ปุ่มพักและความซน 0 หยุดการเดิน แต่ยังปล่อยให้ตกกลับพื้นได้ เมื่อเปิด reduced motion จะกลับพื้นทันทีโดยไม่มีแอนิเมชันการตก
- UI สไตล์ **Claymorphism** พื้นลาเวนเดอร์ การ์ดนุ่มนูน ขอบมน เงาด้านในและด้านนอก ปุ่มยุบเมื่อกด ครอบคลุมสตูดิโอ ตู้เสื้อผ้า คำพูด คลัง และกระดานวาด รองรับมือถือและ reduced motion
- มุมขวาบนเลือกธีม **Light / Dark / System** ได้ ระบบจำตัวเลือกในเครื่องและปรับตาม OS ทันทีเมื่อเลือก System สีของตัวละครไม่เปลี่ยนตามธีม
- ปุ่ม **สีเว็บ** ข้างโหมดสว่าง/มืด เลือกได้ 6 โทน (ม่วง ฟ้า ชมพู พีช ทราย เทา) หรือกำหนดสีเองด้วยวงล้อสีและ HEX ระบบจำสีแยกจากโหมดสว่าง/มืด และซิงก์ตัวเลือกข้ามแท็บของเว็บเดียวกัน ภาพห้องใช้พื้นครีม/เทาอุ่นแทนสีเขียว สีเว็บไม่เปลี่ยนสีตัวละคร
- ปุ่ม **EN / TH** มุมขวาบน เปลี่ยนภาษาได้ทันทีทั้งสตูดิโอ คลัง ชุด อารมณ์ คำพูด กระดานวาด คู่มือติดตั้ง ประวัติ และข้อความแจ้งเตือน จำภาษาแยกจากสี/โหมดที่ `mongbo.language` และซิงก์ข้ามแท็บ ชื่อ คำพูดที่เขียนเอง และงานที่กำลังแก้ไม่ถูกแปลหรือรีเซ็ต ในส่วนขยาย ภาษายังใช้กับ popup และเมนูตัวละครบนเว็บอื่น โดยไม่แก้ภาษาเว็บไซต์เจ้าของหน้า
- Footer แสดง **WaiTy** เป็นผู้สร้าง พร้อมลิงก์ [GitHub](https://github.com/Waiproness) กดปุ่มเล็ก **ความลับของชื่อ** เพื่ออ่านที่มาของ MongBo และความทรงจำถึงโบ้ / โบ๋
- กด **หรือวาดเพื่อนขึ้นมาเอง** เพื่อวาด Pixel Art 32 × 32 มีปากกา ยางลบ ถังสี ดูดสี ขนาดปากกา ย้อนกลับ/ทำซ้ำ และล้างกระดานที่ย้อนกลับได้
- กระดานรองรับเมาส์ สัมผัส ปากกา และคีย์บอร์ด แบบร่างเก็บในเครื่องอัตโนมัติ กด **ใช้ภาพนี้เป็นตัวละคร** แล้วเก็บเข้าคลัง
- ตัวที่วาดเองใช้กับพรีวิว คลัง PNG ไฟล์ตัวละคร และส่วนขยายได้เหมือนตัวสำเร็จ ไฟล์รุ่นเดิมยังเปิดได้
- เปลี่ยนชื่อ ขนาด 64–160 px และความซน 0–100
- กด **เก็บเพื่อนตัวนี้** เพื่อบันทึกในคลัง สูงสุด 30 ตัว คลังเต็มจะไม่ลบตัวเก่าทิ้ง
- เว็บธรรมดา: กด **พาน้องไปด้วย** เพื่อดาวน์โหลด `.mongbo.json` แล้วนำเข้าผ่าน popup ส่วนขยาย
- สตูดิโอที่เปิดจากส่วนขยาย: บันทึกแล้วตัวละครบนแท็บอื่นเปลี่ยนทันที
- ลากเพื่อย้าย คลิกทักทาย ใช้ปุ่มลูกศรหลังโฟกัสตัวละคร คลิกขวาเพื่อเปิดเมนู
- ส่งออกรูป PNG พื้นหลังโปร่งใส หรือไฟล์ตัวละครไว้สำรองได้

## ข้อมูลและความเป็นส่วนตัว

- เว็บเก็บแบบร่างและคลังใน LocalStorage ของเว็บนั้น
- ส่วนขยายเก็บตัวละคร คลัง และการตั้งค่าใน `chrome.storage.local` ชุดข้อมูลนี้แยกจากเว็บ
- ส่งออกไฟล์ก่อนล้างข้อมูลเว็บหรือลบส่วนขยาย เพราะยังไม่มี cloud sync
- Content script ไม่อ่านข้อความ ฟอร์ม รหัสผ่าน หรือประวัติการท่องเว็บ และไม่ส่งข้อมูลออกเครือข่าย
- ใช้ permission `storage` และ `activeTab` พร้อม content script เฉพาะ HTTP/HTTPS ใน top frame
- ไม่มี remote script, CDN, analytics หรือบริการ AI ฟอนต์โอเพนซอร์สมีใบอนุญาตใน `public/fonts`
- หน้าเว็บอาจตรวจพบชื่อ รูปลักษณ์ และคำพูดที่แสดงใน DOM ได้ จึงไม่ควรใช้ข้อมูลลับเป็นชื่อหรือคำพูด

## ข้อจำกัดของรุ่นแรก

- ตัวละครเดินอยู่บนหน้าเว็บ ไม่ใช่บนเดสก์ท็อปนอกเบราว์เซอร์
- หน้า `brave://`, `chrome://`, ร้านส่วนขยาย และหน้าที่เบราว์เซอร์จำกัดสิทธิ์ไม่รองรับ
- ตำแหน่งตัวละครแยกกันในแต่ละแท็บ และเริ่มใหม่เมื่อรีเฟรชหน้า
- หน้าที่มี fullscreen, top-layer dialog หรือแก้ DOM ทั้งหน้าอาจบัง/นำตัวละครออก
- เคารพ reduced motion ของระบบ โดยหยุดเดินและหยุดแอนิเมชันอัตโนมัติ
- ภาพที่วาดเองเป็น Pixel Art เฟรมเดียว ใช้การเด้งและเคลื่อนที่ ยังไม่มีตัวแก้แอนิเมชันหลายเฟรม AI สร้างภาพ หรืออัปโหลดภาพอิสระ
- ส่วนขยายรุ่นนี้ใช้ Developer mode ยังไม่ได้เผยแพร่ใน Chrome Web Store

## โครงสร้าง

- `src/App.tsx` สตูดิโอ React
- `src/popup.tsx` เมนูส่วนขยาย React
- `src/shared` ข้อมูลตัวละคร SVG และการเดิน/ลากที่ใช้ร่วมกัน
- `src/components/DrawingEditor.tsx` กระดานวาดตัวละครและประวัติย้อนกลับ
- `src/components/ColorPicker.tsx` สีอิสระ รหัส HEX และพาเลตสี
- `src/components/WardrobeEditor.tsx` ชุด ของสวมศีรษะ และแว่นตา
- `src/extension/content.ts` ตัวละครบนเว็บไซต์อื่นใน closed Shadow DOM
- `extension` manifest และ service worker
- `scripts/build.mjs` สร้างเว็บ ส่วนขยาย และ ZIP
- `docs/design.md` ขอบเขตและแนวทางออกแบบ

โฮสต์เว็บบน HTTPS ปกติได้จาก `dist/site` การบันทึกออนไลน์ยังเป็นข้อมูลในเบราว์เซอร์ของผู้ใช้แต่ละคน ไม่มีฐานข้อมูลส่วนกลาง

## Cloudflare Pages

ใช้ Node.js 24 ขึ้นไป และ Python 3 สำหรับสร้าง ZIP ส่วนขยาย

```sh
npm ci --ignore-scripts
npm test
npm run check
npm run build
npm run deploy:cloudflare
```

ก่อน deploy ให้เข้าสู่ระบบ Cloudflare ด้วย `npx wrangler login` บัญชีที่มีสิทธิ์ในโปรเจกต์ `mongbo` การ deploy ใช้ `dist/site` และ production branch `main` ตาม `wrangler.jsonc` โดยมี ZIP ส่วนขยายรวมอยู่ด้วย

โปรเจกต์นี้ใช้ Direct Upload การ push ไป GitHub อย่างเดียวจึงยังไม่ deploy อัตโนมัติ เมื่อต้องการย้อนรุ่น ให้เลือก deployment ก่อนหน้าใน Cloudflare Pages แล้วใช้ Rollback หรือ checkout commit เดิมและ build/deploy อีกครั้ง
