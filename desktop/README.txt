MongBo Desktop for Windows x64

Extract the entire ZIP to a permanent folder. Open MongBo.exe from that folder.
Keep all bundled files together. Do not copy the EXE alone.

Double-click the MongBo tray icon beside the clock to manage friends.
Right-click the tray icon to open the studio, pause, hide, choose a display or quit.
Right-click a character for its menu. Drag and release to throw.
Import .mongbo.json files to add friends without replacing existing ones.

This build is offline and unsigned. Windows may warn or block it according to
your device policy. Do not disable Windows security to run this app.
No auto-start, auto-update, online chat or account is included.

Data: %APPDATA%/MongBo/companions.json
The website, extension and desktop have separate libraries. Use JSON to transfer.
Quit before updating. Extract a new version to a new folder; existing AppData
is retained. Removing this program folder does not remove saved companions.
Export important characters from the studio before deleting app data.
